## 0. 方法论更正（重要）

此前浅核验（现 `verify/verify_shallow.json`）结论「11/11 通过、残留=0」**不可信**：

- 该脚本依赖 `entity.bbox()` 计算包围盒，但本机 **ezdxf 1.4.4 的实体对象没有 `.bbox()` 方法**，调用全部抛 `AttributeError` 被 `try/except` 静默吞掉 → 包围盒恒为 `None` → 旧框残差判定**从未真正执行**，残留=0 是“假零”。
- 本次改用 `ezdxf.bbox.extents`，并修复了：① 无限长实体（射线/构造线）把内容包围盒污染成 `Infinity`；② 跨文件复用缓存导致 INSERT 边框退化（宽=0）；③ 旧框比例改用检测阶段 `detection.json` 的**旧框真实比例**比对，而非被标注撑歪的“内容比”。

## 3. 三类问题详述

### 3.1 标题栏空白 / 错填（最显眼，11/11）

模板 `HH_FRAME_A0` 含 15 个属性（TITLE / DWG_NO / SCALE / STAGE / MATERIAL / WEIGHT / VERSION / DATE / SHEET / DESIGN / CHECKED / REVIEWED / APPROVED / COUNTERSIGN）。自动回填情况：

- **TITLE**：仅 `消防系统图`、`首二层商场平面`、`高低压系统` 填到了像标题的文字；其余被抓成了**“注：…同…”注记文本**（天面/弱电1/强电平面/消防弱电2/系统）、**电缆型号** `YJV-5X10 MR`（首二层系统图）、**房间号** `LT2`（裙楼）、或直接**空**（首层配电干线）。
- **SCALE**：仅 `强电平面`、`消防，弱电2` 填到 `1:100`，其余 9 张空。
- **DATE / DESIGN**：11 张**全空**。
- **DWG_NO**：基本全空，但 `系统` 第 2 框被错填成整段注记文字。

> 根因：住宅楼图纸是“打散”图（无块式标题栏），字段提取从散文本里就近抓取，常抓到注记/明细而非真正图名/图号/比例。这是管线字段映射的**质量问题**，不是“没跑完”。

### 3.2 旧图框 / 旧标题栏残线（= 真残留）

`HH_FRAME_A0` 块内 58 个实体**全部位于 `HH_TITLE` 层**，因此新框自身线条**不在** `FRAME` 层。故 msp 中落在框内的 `FRAME` 层线条**必为旧图框残线**：

- **首层配电干线平面图（18 条）**：
  - `#03` 长 118800，`x: 2942→121742`（= 旧框宽）→ **旧框顶边横线没删**；
  - `#02` 长 115400 → 又一条旧框横线；
  - `#04–#18` 一簇集中在右下角 `(102742–120742, −69387~−63762)` 的短线 → **旧标题栏/明细表边框矩形没删**。
- **首二层商场平面（1 条）**：长 115400，`x: 5925→121325`（≈ 旧框宽）→ **旧框顶边横线没删**。

> 根因：这两张旧框非 √2（1.19 / 0.95），新 √2 框经 `fit=max` 单边缩放后**比旧框矮/窄**，新框盖不住旧框 → 旧框顶边 + 旧标题栏区域落在删除逻辑覆盖范围之外而遗留。

### 3.3 非 √2 比例失真（已知限制 #2）

- 8 张旧框为 √2（1.39–1.42），新 A0 √2 框完美贴合，无失真。
- 3 张旧框非 √2：
  - **裙楼消防平面** 旧框 1.77（加宽幅）→ 新 √2 框比旧框窄 → 旧图面内容向两侧溢出；
  - **首层配电干线平面图** 旧框 0.95（近正方形）→ 新 √2 框比旧框矮 → 旧图面上半部冒出框外；
  - **首二层商场平面** 旧框 1.19（轻度）→ 同上但较轻微。
- 这正是案例十摘要里标注的**限制 #2**：非 √2 图幅需补 `HH_FRAME_Ax_WIDE` / 竖版模板。

## 4. 未完工项清单（按优先级）

1. **【高】标题栏属性回填质量** — 改进字段提取/映射：① TITLE 不要抓“注：…”注记、电缆型号、房间号；② SCALE/DATE/DESIGN 明确来源（旧图有无对应文本？无则留空而非错填）；③ 必要时提供人工映射/默认值。影响最显眼。
2. **【中】旧框 / 旧标题栏彻底删除** — 加强删除逻辑，覆盖旧框 bbox 全部范围 + 旧标题栏区域，修掉首层配电（18 条）、首二层商场（1 条）残线。
3. **【中】非 √2 模板** — 建 `HH_FRAME_A4V`（竖版）/ 加宽模板，按旧框比自动选模板，根治裙楼 / 首层配电 / 首二层商场比例失真（即之前“明日可继续”的限制 #2）。
