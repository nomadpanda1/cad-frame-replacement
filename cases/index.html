案例四：装配体图纸（无图框 / 无标题栏）

1 张 DWGA3 横放无 TEXT 标题栏无外框矩形策略二

来源：装配体图纸，二进制 DWG 无代理实体。AutoCAD COM 转 DXF 后，因原图无图框/标题栏，采用"清标题栏占位 + 插公司 A3 图框"：先删右下角 63 个零散标注，再插入 HH_FRAME_A3（14 字段均为可编辑空占位）。这是"无图框"异常场景的鲁棒性验证。

案例七：多图框逐框替换（检测多图框 → 逐框插公司图框）

2 个合成 DXF平铺多框并排多框逐框回填

新开发项成果。在 lib/finder.py 新增 detect_frames_hierarchical（识别"整图纸框"为纸边、其余为替换目标；并排多框无整图纸框则全部替换），在 lib/block_replace.py 新增 delete_frame_border/delete_title_strip（外科手术式删除，只删该帧旧边框+右下角旧标题栏，保留图内几何）。逐框选模板尺寸 → 抽字段 → 删旧框线+标题栏 → 插公司图框(fit=max) → 回填。

  • 查看生成前 / 模板 / 生成后对比
  • 合成 DXF 输入（gen_mf_samples.py 可复现）
  • 逐框检测/抽取/回填/删除结论（JSON）

关键结果：

  • 07a 平铺多框：识别整图纸框(0,0)-(841,594)为纸边，3 个子图框逐框替换，字段 图名/图号/比例/阶段 全部正确回填 ✅
  • 07b 并排多框：无整图纸框（CNG 简化版），4 个 A3 图框逐框替换，全部成功 ✅
