支持 .dxf / .dwg（单文件）



勾选「同时输出 DWG」可额外下载 DWG（服务器 ODA 转换，AutoCAD 2018 格式）。不勾选则只返回 DXF。
使用说明
  1. 选图：点击或拖拽上传 .dxf / .dwg（单文件；DWG 会先经服务器 ODA 无头转换再处理）。
  2. 模板：
    • 自动：按检出旧图框的幅面比例自动匹配 A0~A4 / A4V，加长、竖版图幅也能自适应（运行时等比重定向）。
    • 自定义：勾选「使用自定义模板」上传自己的 .dxf 图框文件（块式或打散式均可自动识别）。
  3. 适配：max 整图幅填充 / tight 紧凑。
  4. 输出：默认下载 DXF；勾选「同时输出 DWG」可额外下载 DWG（ODA 转 ACAD2018）。
  5. 字段迁移：旧标题栏的 图名 / 图号 / 比例 / 材料 / 日期 等自动提取并回填到新框对应字段；识别不了的留空（见诊断信息里的 unmatched，可人工补）。
  6. 高保真模式（本机 CLI）：本机装有 AutoCAD 时，用命令行以 AutoCAD COM 直接编辑 DWG，效果最佳（AutoCAD 原生保存，完全规避 ezdxf 重写带来的编码/结构问题）： python run_skill.py --template templates/HH_FRAME_A4.dxf --dwg --fit max 图纸/*.dwg
已知不足
  • 预览为服务器端渲染（字体/线宽与 AutoCAD 有差异），仅供快速核对，请以下载文件为准。
  • 字段迁移依赖旧标题栏的格式（标签式 / 冒号式）；个别手绘或特殊排版的旧框可能识别不全，请按诊断的 unmatched 人工补充。
  • SolidWorks「打散」图框的残留清理基于检测到的标题栏区域；若旧框与绘图内容大面积重合（如住宅/电气平面图），可能误删或漏删。
  • 自定义模板仅支持 .dxf；.dwg 模板请先在 AutoCAD 中另存为 DXF。
  • DWG 输出为 ODA File Converter 转换（ACAD2018 格式），非 AutoCAD 原生直存，极个别对象类型（如特定代理实体）可能有细微差异。
  • 保真度提示：Web 端是无头 Linux 服务器，无法运行 AutoCAD COM，属「便捷」路线；对复杂/敏感图纸，建议用上面的本机 CLI 高保真模式（AutoCAD COM 直接编辑原 DWG），效果最好。
